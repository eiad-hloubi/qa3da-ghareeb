# قعدة غريب

لعبة جماعية من عيلة **تحدّي ولعب** بمشروع «قعدة». الكل بيعرف الكلمة… إلا الغريب.
إعداد م. إياد حلوبي.

## فكرة اللعبة
- الريس بيفتح القعدة، والكل بيفوت من موبايله بالكود أو الـQR (4 لاعبين عالأقل، لحد 30).
- شاشة «جاهز» فيها موشن «كيف منلعب»، والكل بيبلّش سوا بعد عدّ تنازلي.
- الأدوار بالسر: **منّا وفينا** والـ**غريب** (لحد تلت القعدة).
- **الرئيس** واحد من «منّا وفينا»، بينقّي موضوع وكلمة من البنك (16 موضوع) أو من عنده.
- الموضوع للكل، والكلمة لـ«منّا وفينا» بس. البطاقة بتنشاف بالضغط المطوّل.
- بعد كل دور تصويت. الأكتر أصوات بيطلع. بالتعادل تصويت تاني بين المتعادلين، وإذا تعادلوا ما حدا بيطلع.
- **منّا وفينا بيربحوا** إذا طلّعوا كل الغرباء، و**الغرباء بيربحوا** إذا صار عددهن قد الباقيين.
- النقاط: الفريق الرابح +3، «منّا وفينا» +1 لكل صوت صاب غريب، الغريب +1 لكل سؤال ضل فيه. نفس النقاط = نفس المركز.

## اللي مطبّق من «قواعد قعدة»
- الإطار فوق: كرسي البين باغ واسم العيلة بخط Changa والرجوع، والباقي بالسحّاب (البيت، قدّام، حسابي، فاتح وداكن، التعليمات).
- أيقونة التطبيق الرسمية (ملصق اللوغو + رسمة غريب) بلون العيلة، وملفات التنزيل مربع كامل والتكوين 64%، ونسخة maskable منفصلة، وapple-touch-icon 180.
- الغلاف: الأيقونة، الاسم المباشر، «إعداد م. إياد حلوبي»، موشن، شريط مايل، وزر «نزّل التطبيق».
- الصورة: سيلفي أو معرض، مع قص وتكبير وسحب وتدوير وقلب. صورة الشلة بتلفّ وبتتحوّل بين الطول والعرض.
- أدوات الريس: سكّر هلّق، خلّصنا، قعدة جديدة (بنفس الناس / ناس جدد / من الصفر)، تمرير، إعادة، تغيير الرئيس، والناس (تعديل، تطليع، تسليم).
- حفلة الكشف بـ3 خيارات، وصورة الستوري بـ3 أشكال (ملف التحقيق، بولارويد، مطلوب) بفاتح وداكن، وتحت بس `@eyad.hloubi` و`#qa3da`.
- رجوع تلقائي لنفس القعدة إذا انقطع النت أو تسكّرت الصفحة، واسمي مميّز بكل القوائم، والصوت شغّال.
- الخطوط والأيقونات ومكتبة الـQR مستضافة مع الحزمة. الصور ما بتنكتب عالسيرفر (بالذاكرة بس طول ما القعدة شغّالة).

## التشغيل
```
npm install
npm start      # http://localhost:3000
```

## النشر
- **Render:** ارفع المجلد على مستودع GitHub لحاله، وبـRender اختار New ← Blueprint؛ ملف `render.yaml` جاهز.
- **Docker:** `docker build -t qa3da-ghareeb . && docker run -p 3000:3000 qa3da-ghareeb`
- الإحصائيات: `/stats` · لوحة الإدارة: `/admin` (مفتاحها بمتغير `ADMIN_KEY`).
- رابط «شارك مع صحابك» بأول ملف `public/app.js` (المتغير `IG`)، غيّره لرابط صفحة قعدة لما تجهز.
